# Blood Donor Request System

A client-server based blood donation management system developed in Java using socket programming and Object-Oriented Programming principles.

## Overview

This system allows donors, hospitals, and administrators to interact through a networked application to manage blood donation requests efficiently.

The project simulates a real-world blood donation platform with authentication, request handling, and role-based access.

---

## Features

### Donor
- Register and login
- View donation requests
- Respond to blood requests

### Hospital
- Register and login
- Create blood donation requests
- Manage request information

### Admin
- Manage donors and hospitals
- View all requests
- Monitor system activity

---

## Technologies Used

- Java

## How to Run

1. Compile the server and client files.
2. Start the server.
3. Run one or more clients.
4. Register or login as:
   - Donor
   - Hospital
   - Admin
